## 5. 五条结论

### ✅ 结论 1：重要性护栏把效用损伤打到 **精确 0**
`imp_emb` 的 `hit_answer` = **0.0%**，在**两种注入形态 × 三个比例**共 6 个设置下全部为 0，而基线 `sim_emb` 是 4.0–5.7%。

→ **V2 里唯一遗留的效用风险（1/20 的合并混入非答案内容）被一个简单硬约束彻底消除。**

### ✅ 结论 2：双约束同时把两个目标归零
`cons_imp_emb`：`hit_answer` = **0.0%** 且 `mix_sens` = **0.0%**（分散式三个比例全部成立）。

→ **"零效用损伤 + 零敏感混合" 可以同时达到**，而且簇数与纯相似度相同（1066/1988/3997），**不牺牲压缩率**。

### ⚠️ 结论 3：隐私护栏是**冗余的**，重要性护栏才是功臣
`cons_emb ≡ sim_emb`（簇数和三个指标完全相同，两种注入形态都如此）。

→ 因为相似度合并**本身**就把 `mix_sens` 压到 ≈0，隐私约束一次都没触发。
→ **可发表的核心机制是"相似度合并天然隔离敏感内容"，而工程上真正需要加的约束是"重要性护栏"。** 这个分工很干净。

### ✅ 结论 4：分散式注入下相似度优势**更大**
随机合并的 `mix_sens`：分散式 **20.0 / 18.4%** vs 连续块 17.3 / 15.8%。

→ 敏感内容越分散，随机合并越容易跨边界，而相似度合并依然稳定在 0.0%。
→ **这解除了 V2 里"结论依赖连续块注入"的疑虑。**

### ⚠️ 结论 5：距离有界聚类**不解决效用**
`bound_emb`（PACT 式的 τ 下界 + 簇≤4）：`mix_sens` 0.0%，但 `hit_answer` 仍是 **5.1%**（比 sim_emb 的 4.0% 还高）。

→ **PACT 原样的"距离有界"只能保隐私，保不了效用；效用必须靠重要性约束。** 这正好是我们相对 PACT 的**增量所在**。
