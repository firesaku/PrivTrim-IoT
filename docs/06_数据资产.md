### 1.2 样本 schema

```json
{
  "sid": "smartbench_tdcs_0000",
  "source": "smartbench_tdcs",
  "question": "...",
  "context": "<注入敏感块后的上下文>",
  "answers": ["..."],            // 仅 SQuAD / HotpotQA 有金标准
  "canaries": [                  // 每例 3 个合成敏感标识符
    {"type":"email","value":"contact.<hex12>@example.invalid","marker":"<hex12>","fragment_length":6},
    {"type":"phone","value":"+1-202-555-XXXX","marker":"1202555XXXX","fragment_length":8},
    {"type":"account","value":"ACCT-<hex12>","marker":"<hex12>","fragment_length":6}
  ],
  "variants": [...],             // 每型 4–5 个改述/格式变体
  "canary_position": "prefix|middle|suffix|scattered",
  "meta": {...}
}
```

**注入位置轮换**：prefix / middle / suffix（块式）；scattered（分散式）

## 5. 复现步骤

```bash
# 1. 环境：任意有 numpy 的 Python 3.12；端到端需要 torch 2.6 + transformers 4.57（项目 .venv-main）
PY=/dpc/kuex0095/100065732/privtrim_iot_hpc_20261005/PrivTrim_IoT_HPC_20261005/.venv-main/bin/python

# 2. 离线可行性（CPU，秒级）
$PY code/v2c_feasibility.py --samples data/frozen_samples.jsonl \
    --out out/v2c.txt --json out/v2c.json --ratios 0.125,0.25,0.5 --cap 200

# 3. 约束消融（单卡 GPU）
$PY code/v3_batch.py --config guard --datadir data --outdir out \
    --model <XLM-R snapshot> --cap 200

# 4. 端到端（单卡 GPU，~30 分钟）
$PY code/e2e2.py --cases <cases.jsonl.gz> --lm <Qwen2.5-7B> --emb <XLM-R> \
    --scorer <evaluate-v2.0.py> --n-per-dataset 500 --win 16 --dtype fp16 ...

# 5. 与基线 join（CPU，秒级，需读 results.sqlite）
$PY code/join_baseline.py
```
