# 23 · 复现配置

> 本文只说明**技术配置**：模型、精度、解码参数、数据、评分器、运行方式。
> 任何具体平台、账号、路径与调度器信息均不在仓库内。

---

## 23.1 硬件要求

| 项 | 要求 |
|---|---|
| 加速卡 | **1 × 80 GB 级 GPU**（显存不足时缩小批大小） |
| CPU | 外部方法压缩与 Perception Compressor 可在 CPU 上跑，24 核 / 64 GB 足够 |
| 运行方式 | 各分片为独立进程，可并行亦可串行；不依赖任何特定调度器 |

所有脚本只通过命令行参数与 `PT_ALIAS_KEY` 等环境变量配置，不含硬编码路径。

---


## 23.2 运行环境

```bash
python >= 3.11
torch, transformers (>= 4.44)
llmlingua (0.2.2)          # LLMLingua-2 / LongLLMLingua 基线
sentence-transformers      # Provence 基线
nltk, scipy, numpy
```

两个可选的外部方法需要各自的原始仓库（见 `docs/12`、`docs/21`）：
- **Perception Compressor**（NAACL 2025）：依赖 `meta-llama/Llama-2-7b-hf`、
  `meta-llama/Meta-Llama-3-8B-Instruct`（仅 tokenizer）、`sentence-transformers/all-MiniLM-L6-v2`
- **INTACT**：依赖 `mistralai/Mistral-7B-Instruct-v0.3`

> `code/pc_stubs/` 提供三个空壳模块（`icecream` / `seaborn` / `pynvml`），
> 用于绕开 Perception Compressor 中"只 import、从不调用"的依赖。

## 23.3 模型与解码参数

| 项 | 值 |
|---|---|
| 主模型 | **Qwen2.5-7B-Instruct** |
| 跨模型验证 | **Mistral-7B-Instruct-v0.3** |
| 精度 | `fp16` |

## 23.5 预算与臂

```text
预算点    : 0.25 / 0.50 / 0.75（主实验）
            0.05 / 0.10 / 0.15 / 0.20（预算曲线）
外部方法  : 统一压到 50%（原码固定 n//2），主对比锚定 OURS@0.50
```

21 条内部臂（见 `code/longctx/e2e_longctx_r5full.py` 的 `ARMS`）：

```
full, delete, alias                       （整段处理，无预算）
budget_cluster / budget_cluster_link      （原文 + 冗余删 / +锚点保护）
budget_random                             （随机删，下界）
delete_budget, alias_budget, alias_budget_link
```

## 23.6 关键运行开关

| 开关 | 作用 | 默认建议 |
|---|---|---|
| `PT_ALIAS_KEY` | 打乱别名字母分配顺序，**消除秩泄漏** | **必须设置**（否则攻击者可 100% 逆推别名） |
| `--alias-question` | 问题中的实体同步替换为别名 | 开启（消融显示 +0.2053） |
| `--ext-arms` | 外部方法压缩产物清单 | 见 `code/build_ext_arms.py` |

> ⚠️ 未设 `PT_ALIAS_KEY` 时别名按值升序发放，攻击者已知值集合即可完全逆推。
> 该问题与修复见 `docs/21` 第 21.1 节。

## 23.7 复现主表的步骤

```bash
# 1) 解压数据
gunzip -k data/longctx_max.jsonl.gz

# 2) 全量主实验（21 臂，32 分片，启用别名秩泄漏修复）
export PT_ALIAS_KEY='<your-key>'
python code/longctx/e2e_longctx_r5full.py  # 分片见下 #keyfull

# 3) 外部基线压缩（5 个方法，各 32 分片）
python code/longctx/e2e_longctx_r5full.py  # 分片见下 #extcomp
python code/longctx/e2e_longctx_r5full.py  # 分片见下 #extnew

# 4) 外部基线评测
python code/longctx/e2e_longctx_r5full.py  # 分片见下 #extevalfull

# 5) 汇总（本地即可，无需 GPU）
python code/analyze_keyfull.py
python code/analyze_ext.py
```

预算曲线：`e2e_longctx_r5full.py --ratios 0.05,0.10,0.15,0.20`；跨模型：换 `--model` 为 Mistral-7B-Instruct-v0.3；公开基准：`ext_compress.py` + 对应评测入口。

## 23.8 已知偏差（复现时须知晓）

1. 运行**非逐位可复现**：同臂两次运行 F1 差约 0.0006（fp16 算子非确定性），
   小于 0.001 的差异不作方法解释
2. `batch=8` 比 `batch=2` 慢约 25%，且 4/1806 条预测不同，故主实验用 `batch=2`
3. DAC 基线在长上下文上大量 OOM，仅覆盖 300/2728 例，不可与全量并列
4. Perception Compressor 的 guiding questions 由 Qwen2.5-7B 生成（原作者未发布生成脚本）
