口径：完全复刻 `common.py` 的 `redact()` / `normalize_identifier()` / `exposure()`；**0 次模型调用**。

## 4. 读法

- `0_canonical` 行是现有成绩的来源：正则在原始格式上是 100%。
- 非 canonical 行就是**正则结构上做不到的地方**，也是导师点名要求覆盖的 paraphrase 场景。
- `D_看不见_未删除` 是最危险的一格：泄漏发生了，但现有指标**测不出来**，所以 1.000 的移除率并不代表安全。
