Keeping the Referent in the DARK

Self-contained pages. No server, no dependencies, no network calls.

interactive.html — click through it Sixty real cases from the benchmark. Pick one, see the four policies side by side, and drop lines yourself: the leak indicator re-scans what you leave on screen and turns red the moment a protected value survives. Includes a "hide the answer" switch if you want to guess first, and a filter for the cases where DARK answers and both alternatives fail. dark_demo.html — the short version Three cases laid out to be read rather than clicked, with a walkthrough of the conflict, the 2,728-case results and the gold-in-context heatmap. Start here if you have two minutes; use the interactive page if you want to take it apart. zeal_demo_en.html — separate exploration An interactive note on a different mechanism (a public shift with shared-bit dropping) and the configurations it cannot reach. Not part of this paper's results.
Everything here is generated: python src/make_demo_interactive.py and python src/make_demo.py read results/percase/ and the benchmark itself, so the pages cannot drift from the paper. An earlier PrivTrim demo in this folder predated the benchmark expansion and quoted figures that no longer matched the paper; it has been removed rather than left to mislead.
