CAN'T ✗ — the four walls of Zeal

✗
Single values — the cloud learns the mean, never your reading. Noise stays inside every sent value; only the fleet average de-biases when Ā is removed (Theorem 1).
✗
Time-series / patterns — each sample is treated independently. Zeal sees scalars, not sequences: your 24h daily routine shape is not modeled or protected as a pattern.
✗
Needs a known reading range — Ā must be designed for the span. No range → can't choose Ā → can't guarantee shared bits or 100% reachability.
✗
Text / AI prompts — Zeal only shifts numbers. Try it: send a sentence "through Zeal" below.

Protocol — reproduce the paper's points

① slide ε: watch eε and noise scale — smaller ε, blurrier data
② drag Ā to 0, or right onto the 256 boundary: shared prefix collapses (γ ↓, TR ↑) and reachability holes open — this is Theorem 7's Ā condition
③ press ↻ re-roll: per-device recovered values move, mean stays ≈ true — unbiasedness in action
Mapping to the paper: ε = privacy budget (ratio bound eε); Ā = public shift, added on-device, subtracted by the server (Theorem 1 unbiased mean); shared prefix = identical top float bits, dropped before transmission — wire ratio (64−γ)/64 (Theorem 6); reachability = fraction of float values that can occur — 7–30% without Ā, 100% with it (Theorem 7); the two combs below are a toy version of the paper's Fig. 7 logic: the bead step Δ vs shelf spacing ULP decides whether floats get skipped — and skipped differently per input — which is exactly the leak Ā closes; γ here uses a 16-bit toy word for readability.
